## Default Permission

Everything the viewer's TauriEngine calls: opening, reading and closing documents. Pages are served over the papyra:// protocol, which needs no permission.

#### This default permission set includes the following:

- `allow-open`
- `allow-close`
- `allow-page-text`
- `allow-outline`
- `allow-links`
- `allow-page-labels`
- `allow-attachments`
- `allow-attachment-data`
- `allow-struct-tree`
